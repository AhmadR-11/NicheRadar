# NicheRadar 🎯

Automated Lead Research workflow for n8n.

## Features
- **Form Trigger**: Collects City, Country, Niche, and Custom Research Questions.
- **Reddit Integration**: Fetches relevant posts via Reddit API.
- **Multi-Source Links**: Generates instant links for LinkedIn, Google Maps, Facebook, and Yelp.
- **Google Sheets Integration**: Creates a new Google Sheet automatically and logs formatted research results.

## Setup & Usage
1. Import `lead_research_n8n_workflow.json` into your n8n instance.
2. Connect your Google Sheets OAuth2 / Service Account credentials.
3. Activate the workflow and submit the generated form!
